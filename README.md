# convex-invite

Reserved package name for a secure, reusable invitation component for Convex.

## Status

This `0.0.0` release is a non-functional placeholder. Do not use it in an
application yet.

The planned component will provide hash-only invitation tokens, single-use
acceptance, decline, expiry, revocation, resend-as-replacement, idempotent
acceptance, and delivery-attempt bookkeeping while leaving authentication,
transport, and domain grants with the host application.

See [the v0.1 PRD](./convex-invite-v0.1-prd.md) for the proposed contract and
implementation plan.

The working license target for the future implementation is Apache-2.0. This
placeholder release is currently unlicensed.
