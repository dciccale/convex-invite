# convex-invite

This package version reserves the npm `latest` tag for the Apache-2.0-licensed
`convex-invite` Convex component.

The implemented release candidate is available from the npm `next` tag:

```sh
npm install convex-invite@next
```

See the [project repository](https://github.com/dciccale/convex-invite) for the
component source, documentation, and security guidance.
